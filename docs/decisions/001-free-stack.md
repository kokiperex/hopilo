# Decisión 001: stack gratuito

## Estado

Aceptada.

## Decisión

Hopilo utilizará TypeScript, Vite, Three.js y Rapier 3D.

## Motivo

Esta combinación permite crear el juego web 2.5D con gráficos y física 3D sin licencias pagadas ni servicios obligatorios. También facilita publicar una versión estática.

## Consecuencia

El MVP evitará assets, plugins, dominios y servicios comerciales. Los recursos externos deberán tener una licencia gratuita y compatible con el proyecto.
