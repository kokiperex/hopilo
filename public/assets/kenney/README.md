# Kenney assets used by Hopilo

This folder contains a curated, lightweight subset of these Kenney packs:

- Marble Kit — decorative fan and banner.
- Nature Kit — palm, tree and rock decorations.
- Modular Space Kit — gate and cables for the space world.
- Platformer Kit — moving block and conveyor decoration for the wood world.
- Mobile Controls — pause, jump, left and right control icons.

All included files are released by Kenney under CC0. The full license is in `LICENSE.txt`.

The game keeps its physics and colliders in TypeScript primitives. The GLB files are optional visual decoration only, so the level remains playable if an asset cannot be loaded.
